# 自动网卡识别与周期流量

更新 Server 与 Client 后，Client 会自动发现系统中的网卡并采集各自的接收 RX、发送 TX 累计字节。总管理员在 Client 详情 → 网卡流量中选择日期，查看每张网卡的周期用量。

## 网卡与统计口径

- 自动列出设备网卡、网桥、聚合、虚拟和回环接口，不写死 `eth0`、`ens3` 等名称。默认根据默认路由建议选择一张在线主出网卡；没有默认路由时优先选择在线设备网卡。
- 每张网卡独立保存。可选择“单向发送 TX”“单向接收 RX”或“双向（接收＋发送）”，也可手动勾选多张网卡汇总。默认不会将所有网卡直接相加。
- 网桥、VLAN、隧道和底层网卡可能观察到同一份数据。网卡合计是所选接口的字节之和，不能自动判断哪些接口重复。请选择符合业务目标或服务商口径的接口。
- 网卡数据包含经过该接口的所有程序和协议，不限于 Realm。与按 Realm 监听端口计量相比，网卡统计更接近设备层流量，但与服务商账单仍可能因测量位置、协议开销及统计规则不同而有差异。

## 采集与历史

- Linux/OpenWrt 使用 [`/proc/net/dev` 和 sysfs](https://www.kernel.org/doc/html/latest/networking/statistics.html) 读取接口、元数据及计数器，不需要 nftables，也不修改网卡、路由或防火墙。
- Windows 使用 [`Get-NetAdapterStatistics`](https://learn.microsoft.com/en-us/powershell/module/netadapter/get-netadapterstatistics) 与网卡、默认路由信息采集。需要系统具备相应的 PowerShell NetAdapter 模块及读取权限。
- 容器部署只能观察其所在网络命名空间内的接口；统计宿主机网卡应在宿主机或 Host 网络中运行 Client。
- 从首次有效采样建立基线，不能恢复升级前没有逐网卡采集的历史。增量按北京时间归入当前样本日期，包含起止日期当天，单次最多查询 366 天。
- 主机启动代次与接口索引用来识别重启、接口重建；计数器回退时从新值继续累计。主机重启前未上报的尾部流量可能丢失，长时间断报后跨日期的用量无法精确拆分。
- 接口消失后保留已记录的历史。有所选周期用量的旧接口仍会展示为“本次未上报”；重新发现或新增接口会更新列表。接口名称或 MAC 改变后作为另一条接口身份保存。
- 每日汇总独立于原始快照清理保存，删除 Client 时一并删除其网卡流量历史。整机接口数据只向总管理员开放，区域账号继续使用其授权范围内的链路统计。

查询接口：`GET /api/v1/agents/{agent_id}/interfaces/traffic?from=2026-11-01&to=2026-11-18`。
