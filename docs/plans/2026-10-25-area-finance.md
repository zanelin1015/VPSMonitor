# 区域账号精简财务方案

确认日期：2026-10-25。状态：已确认，待实施。

区域账号作为代理商，线下通过支付宝口令红包或 USDT 转账收款，人工确认后新增账号或线路。系统记录收支，不接入自动支付。

1. 财务页面展示本月收入、支出、利润，以及收支明细。
2. 收入记录关联客户或线路，人工填写金额、币种、收款方式、日期和备注。
3. 支出记录人工填写向主站支付的资源费及其他费用。
4. 代理商独立设置客户售价，不影响主站定价。
5. CNY 和 USDT 分别统计，利润按实收减实付计算。
6. 区域账号只查看自己的账本，主管理员可以查看全部。
7. 继续使用 SQLite，增加独立账本表。
